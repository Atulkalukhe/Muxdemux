THE BIG IDEA

Two circuits. Two directions.

n → 1

Multiplexer · MUX

A MUX is a many-to-one selector. It reads the select bits, then connects one chosen data input to its single output.

Think: many roads merge into one.
1 → n

Demultiplexer · DEMUX

A DEMUX is a one-to-many distributor. It reads the select bits, then sends its one data input to one chosen output.

Think: one road splits toward a chosen exit.
✳

Where are they used?

MUX: data selection, communication channels, sensor reading, and CPU buses.

DEMUX: data routing, serial-to-parallel systems, memory decoding, and control signals.

↔

MUX vs DEMUX

Both use binary select lines. A MUX chooses which input to read. A DEMUX chooses where to send the input.

Same address rule: channels = 2n
